Task 3: Random Password Generator

Description

This is a Python-based Random Password Generator that creates passwords according to the user's selected preferences.

Features

- User can enter the password length (minimum 8 characters).
- Choose uppercase letters.
- Choose lowercase letters.
- Choose numbers.
- Choose special symbols.
- At least two character types must be selected.
- Generates a password based on selected criteria.
- Input validation for incorrect entries.
- Option to generate another password.

Technologies Used

- Python
- Random Module
- String Module

How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

python password_generator.py
